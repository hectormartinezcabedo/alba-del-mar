# Alba del Mar — tienda online (demo)

Web de demostración de la colección Verano 2026 de Alba del Mar: desfile con vídeo guiado por el scroll, catálogo de 38 modelos en 71 colores, filtros, fichas de producto y páginas de información.

Se publica con GitHub Pages desde la rama `main`. Para verla en local, abre `index.html` en el navegador.

Pendiente: precios, tallas confirmadas, datos de contacto y datos legales de la empresa.
